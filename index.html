REAL HARDWARE

Build it on your ESP32

  1. Disconnect USB power before wiring.
  2. Place an LED on the breadboard.
  3. Connect GPIO 2 through a suitable current-limiting resistor to the LED anode.
  4. Connect the LED cathode to GND.
  5. Double-check polarity and wiring before reconnecting USB.
Use the exact GPIO and wiring appropriate to your board and kit. Never connect an LED directly across a power supply without current limiting.

Arduino IDE: first blink sketch

Open Arduino IDE, select your ESP32 board and correct port, then upload this example only after checking your wiring.

const int LED_PIN = 2;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(1000);
  digitalWrite(LED_PIN, LOW);
  delay(1000);
}
